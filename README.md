# Семейная кулинарная книга

Сайт с рецептами нашей семьи. Рецепты хранятся обычными текстовыми файлами,
сайт собирается автоматически и публикуется на GitHub Pages.

## Как добавить рецепт

1. Откройте папку `src/content/recipes/` и скопируйте файл `_шаблон.md`.
2. Назовите копию латиницей через дефис, без «_» в начале: `blinchiki.md`.
   Имя файла станет адресом страницы: `…/recipes/blinchiki/`.
3. Заполните поля сверху (между `---`) и текст ниже.
4. Сохраните, сделайте коммит и пуш. Через пару минут рецепт появится на сайте.

Это можно сделать прямо на github.com, даже с телефона: в папке
`src/content/recipes` нажмите **Add file → Create new file**.

### Поля рецепта

| Поле | Обязательно | Пример |
|---|---|---|
| `title` | да | `Блинчики` |
| `author` | да | `babushka-valya` — имя файла человека из `src/content/people` |
| `category` | да | одна из: супы, вторые блюда, выпечка, салаты и закуски, заготовки, десерты, напитки |
| `servings` | да | `4` — на сколько порций рассчитаны количества |
| `added` | да | `2026-10-02` |
| `ingredients` | да | список, см. ниже |
| `time`, `origin`, `occasions`, `tags`, `photo` | нет | |

Ингредиент записывается одной строкой:

```yaml
- { name: Мука, amount: 500, unit: г }
- { name: Молоко, amount: 1, unit: стак., note: "гранёный, 200 мл" }
- { name: Соль, unit: по вкусу }
- { group: Начинка, name: Капуста, amount: 1, unit: кг }
```

- `amount` — только число (дробные через точку: `0.5`). По нему работает пересчёт порций.
  Если количество «по вкусу», `amount` не пишите.
- `unit` — сокращённо, чтобы не склонять: г, кг, мл, л, шт., ст. л., ч. л., стак.
- `note` — пояснение. **Если в тексте есть запятая, возьмите его в кавычки.**
- `group` — если продукты делятся на части («Тесто», «Начинка»).

Текст под шапкой — обычный Markdown: `## Как готовить` с нумерованным списком,
`## История`, `## Заметки`. Строка, начинающаяся с `>`, выводится «от руки» —
удобно для любимых фраз автора рецепта.

### Фото

Положите картинку в `public/images/` (лучше до 1500 px по ширине) и укажите
в рецепте `photo: images/blinchiki.jpg`.

## Как добавить человека

Скопируйте `src/content/people/_шаблон.md`, назовите латиницей (`ded-kolya.md`).
Имя файла без `.md` потом пишется в рецепте в поле `author`.

## Разделы

Список разделов задан в `src/lib/categories.ts`. Новый раздел добавляется туда,
после этого его можно указывать в рецептах.

## Если сборка упала

Сайт проверяет каждый рецепт. Если поле забыто или раздел написан с ошибкой,
сборка остановится, а во вкладке **Actions** на GitHub будет написано, в каком
файле и какое поле не так. Старая версия сайта при этом продолжит работать.

Частые причины:
- `author` указывает на человека, которого нет в `src/content/people`;
- раздел написан не так, как в списке (например, «Выпечка» с большой буквы);
- запятая в `note` без кавычек;
- в `amount` написан текст вместо числа.

## Публикация на GitHub Pages (один раз)

1. Создайте репозиторий на GitHub и загрузите в него эту папку.
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Сделайте любой пуш в ветку `main`. Сайт появится по адресу
   `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Адрес и подпапка подставляются автоматически, настраивать ничего не нужно.

**Важно:** на GitHub Pages сайт виден всем, у кого есть ссылка. Если не хотите
публиковать полные имена и личные детали, пишите без фамилий. Закрыть сайт паролем
можно позже, перенеся его на Cloudflare Pages с Cloudflare Access; код менять не придётся.

## Работа на компьютере

Нужен Node.js 22 или новее.

```bash
npm install      # один раз
npm run dev      # сайт на http://localhost:4321, обновляется при сохранении файлов
npm run build    # проверить, что всё собирается
```
